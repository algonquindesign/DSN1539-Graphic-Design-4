Weekly Schedule · Assignment 3: Logo Standards Guide

WEEK 13 - Third section of the guide

Due at the beginning of class - Digital-PDF set up artwork in SPREADS uploaded to Brightspace - all pages from Cover to these following new additions.

  • Symbol only - Icon or symbol of the logo. Explain how and when it can be used as a whole or pieces. Can it be broken apart and parts of it used for the design in marketing materials. If yes, how and when.
  • Graphic treatment (watermark) - How the symbol or icon can be used as a graphical element. Provide a visual representation. Do not give only a % for tonal value, also provide an example, so they have a visual to reference. Example - when you use the icon in the background and shade it back. Do this for both the colour and BW. You can also show what range of % you are allowing for tonal value(s) for other graphic treatments here as well.
  • Stationery - Letter Head + Business Card + Envelope. After laying these out you can also use a PSD file to show these items produced. There are plenty online to use.
  • Applications - Logo in use on promotional signage and items (front of the store, cups, hats, vehicles. Use Photoshop to superimpose your logo on items and in areas. Photography - how all photography should be handed from a look branding perspective. (You CAN use stock photography for this and alter it if need be).
  • Show inside back cover
  • Back Cover - Contact info (Company and if you like a designer) - You can place this on cover/back cover or any way you see fit.

WORKING ON FOR WEEK 14 Final Submission


1) Interactive single page PDF file - you will share your screen for the class to view and just walk us through the pages

1) Interactive PDF file:
You will create one Interactive PDF file of your logo branding guide (8.5" x 11" landscape or portrait). Export this file as PDF Interactive single pages. Start with the cover, eliminate the inside cover page (and any other blank pages that do not have information on them) and have contents page start after the cover. The cover will be page #1 and so on. You may have to adjust inside page numbers for interactive pages.

The table of contents should link to each section.

NOTE: Because this is an interactive pdf that would be viewed on screen only the page count does not matter as it would with the PDF for print file.

Label your PDF accordingly – fullname-section-assignment3.pdf (Example: davidbromley-020-assignment3.pdf)

2) Packaged InDesign files spreads with docket sheet

2) InDesign Packaged file:

  • Package your InDesign file.
  • Set up this file save with spreads
  • You will show the cover, inside cover then the contents page which will be P#1 because we are treating this as a separate cover.
  • Your file should have style sheets, cleaned out swatches and fonts.

  • Include in the folder a timesheet
